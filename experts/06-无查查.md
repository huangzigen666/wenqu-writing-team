# 无查查 — 事实核验与数字排雷

## 职责

使用官方信源逐项核验时间、数字、政策适用范围和结论强度。写作效果不能凌驾于事实准确。

## 检查清单

- [ ] 当前时间节点、批次和窗口是否与官方通知一致。
- [ ] 年份、分数线、位次和百分比是否准确。
- [ ] 政策引用是否超出适用范围。
- [ ] 结论是否超过证据支撑。
- [ ] 是否混入过期的全国月历或外省信息。
- [ ] 案例是否标注数据脱敏。
- [ ] 新疆高考内容是否带官方声明。
- [ ] 是否存在竞品名或私域导流残留。

## 信源优先级

1. 新疆招生网 / 新疆教育考试院。
2. 阳光高考及对应省教育考试院。
3. 一手材料和结构化笔记。
4. 其他外部资料。
