## 五、选题方法

1. **扫平台：** 抖音/小红书/视频号/头条/企鹅号，搜相关关键词，看热门和评论区钉住问题
2. **感受心理：** 先感受用户此刻的真实心理状态，不先翻笔记库凑选题
3. **查官网：** xjzk.gov.cn 验证时效性
4. **出选题包：** 2-3个，含标题/判断/认知落差/评论区信号

## 九、对抗审查流程（张素材专用）

> 武装自 `reason-grill-for-claude`（xiaolai）五维攻击框架

张素材对每篇内容做五维攻击：

| 维度 | 审查重点 | 输出标记 |
|:----|---------|:--------:|
| **逻辑** | 推理链条是否完整？有无跳跃或循环论证？ | P0/P1 |
| **证据** | 数据/来源是否可靠？有无断章取义？ | P0/P1 |
| **反方** | 对立观点是否被公平对待？有无刻意回避的视角？ | P0/P1 |
| **假设** | 论证依赖哪些未明说的前提？它们成立吗？ | P0/P1 |
| **诚信** | 是否如实对待反方证据？有无隐瞒关键信息？ | P0/P1 |

P0 = 不修就不能交付。P1 = 建议优化。审查不是找茬，是让内容更扎实。

### 循环任务安全门（来源：ClauDepot Agent Loop批判 · 2026-07-26审查通过）

任何包含自动重试、工具调用或多轮自修复的任务，启动前必须定义：
- 最大步数/时间/成本预算
- 成功条件和失败退出路径
- 相同错误不得无条件重复；重试前必须分类错误并改变输入、策略或执行环境
- 存在写操作时，必须使用幂等键、执行记录或人工确认，防止重试造成重复副作用

### 执行图选择（来源：ClauDepot Agent Loop批判 · 2026-07-26审查通过）

多步骤任务先标注依赖关系：
- 无依赖且资源允许的步骤可以并行
- 存在数据依赖、共享写入或顺序验证的步骤必须串行
- 不得把「使用DAG」本身当作先进性证明，选择依据必须是可验证的延迟、成本和正确性收益

### 长任务状态管理（来源：ClauDepot Agent Loop批判 · 2026-07-26审查通过）

上下文不得依靠完整对话无限累积。每阶段应保存结构化状态：
- 当前目标、已验证事实、未解决问题
- 原始证据位置和下一步
- 压缩或交接后必须能够从原始证据恢复关键结论
- 摘要不能替代证据

## 十、方法论来源

### 来源1：得到品控手册11.0（2025年5月）

**AI赋能原则（KM015-KM022）：**
- AI蓝军要服务于公司核心使命，不追炫酷边缘技术。避免三大误区：技术崇拜、AI团队孤岛化、过度依赖外部顾问。
- 保持「警觉但不焦虑，行动但不冒进」的推进节奏。
- AI负责发散，人负责收敛。AI是辅助人提升效率，不是替代人的核心创造性工作。
- 「知识服务未来界面可能不是人与人，但背后和目标永远是人与人。」

**金线品控五维标准（KM026）：**
- 要素做到位、交付质量高、得到气质足、品牌增值多、X因素突出。
- 对应周审稿的品控维度，可补充「X因素」——即主理人独特魅力带来的不可替代性。

**知识萃取闭环（KM003/KM033-KM035）：**
- 智能体回答不了→触发知识萃取→审计后入库→成为组织新知识。
- 「知识萃取先于工具部署，个体创造终将融入组织智能。」

**课程研发逻辑（KM028-KM032）：**
- 课程本质不是灌输知识，而是帮用户建立新认知模型。
- 核心结构：挑战-解决方案。世界由挑战构成，知识用来回应挑战。
- Aha时刻 = 用户认知模型发生改变的时刻。
- 隐性攸关者原则：对当前用户、未来用户、用户社会关系、知识共同体等8个层面负责。

**评稿会机制（KM034）：**
- 四要素：业务真实、效果可感、对象相关、供应稳定。
- 优先选择生产中的案例，既要展示问题原貌也要展示修改示范。
