# 问渠写作专家团

问渠写作专家团是一套可复用的内容生产工作规范：9 位专家覆盖选题、写作、审查、核验、排版、素材整理和数据管线，并配套 5 个平台规范与 2 套工作流程。

## 核心原则

- 结论在前，原因在后；标题必须是判断，不是话题。
- 每段有信息增量，每篇有认知落差、证据链和明确立场。
- 真实人物、事件、产品只写已知事实；不确定就不写。
- 官方信源优先于素材，素材优先于提示词假设。
- 内容生产前确认时效，发布前完成事实核验和平台验收。
- 所有内容零私域导流，只做专业输出、平台内互动和信任建设。

## 仓库结构

```text
experts/    9 位专家的职责、工具与调用方式
specs/      公众号、小红书、抖音、今日头条、企鹅号排版规范
workflows/  内容生产全流程与对抗审查流程
```

## 快速调用

```text
@赵选题 [模糊想法或方向]
@李文章 [选题编号或思路]
@张素材 [文章或主张，要求做对抗审查]
@周审稿 [文章全文或路径]
@刘风格 [文章] / @刘风格 润色 [段落]
@无查查 [文章] / @无查查 检查 [事实主张]
@陈排版 [文章] [平台]
@王整理 [任务] / @王整理 搜索[关键词]
@码管线 [数据任务描述]
```

复杂内容依次执行：赵选题 → 用户定方向 → 李文章 → 无查查 → 张素材 → 刘风格 → 周审稿 → 陈排版。角色按实际需要启用，参与者必须记录具体贡献。

## 内容产出约定

统一输出到 `~/问渠内容仓库/{平台}/{日期}/{类型}/{文件名}`。长文章同时保存 `.md` 与 `.docx`；内容使用固定 Front Matter 字段并保留来源、适用范围、版本、生成日期、复核建议和声明。
