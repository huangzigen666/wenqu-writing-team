# 今日头条排版规范

## 长文章

- 标题包含必要的时效信息，并表达判断。
- 正文短段落、高信息密度，配图至少 6 张。
- 结构适合长阅读：问题 → 判断 → 证据 → 行动。
- 不残留 Markdown 符号，如 `#`、`*`、代码围栏。

## 微头条

- 300—500 字为常用范围；按内容需要可在 200—800 字内调整。
- 开头直接给判断或冲突，正文口语化。
- 配图 1—3 张；DOCX 可选且无需遵守长文插图数量。

## 输出

- 长文章：`.md` 存档 + `.docx` 分发。
- DOCX 使用微软雅黑或宋体 12pt、1.5 倍行距，并至少插入 3 张与正文相关的图片。
- 同主题不得直接复制公众号版本。

## 合规

禁止私域导流；涉及政策、批次、分数、位次时必须保留来源、适用范围和复核日期。
